A recorded journey through independent approval, verified target execution and an audit trail. Captions explain each step; use the presenter notes for live narration.

1. Assess consequences

Inspect new resources, changed authority and critical access paths before granting a role.

2. Require independence

Ordinary finance access needs its owner. Critical wallet access needs two distinct eligible security leads.

3. Verify the outcome

Confirm target read-back, probe real simulator access, inspect audit history and revoke the demonstration roles.

Scope: The recording uses a stateful local exchange simulator and native Chromium WebAuthn with virtual CTAP2 devices. It is not a physical hardware-key test or full product certification. Executable containment, complete restoration and automatic expiry/drift correction remain outside this demo.

For the prepared live console, run python scripts/demo.py present from the repository. Runtime and private presenter credentials are kept separately from this shareable package.
